# Habitat selection on settlement of dispersal in fragmented landscapes - Individual-based model

This is a repository for sharing an individual-based model (IBM) developed based on a previous IBM (https://github.com/LEEClab/small_mammal_dispersal_model) parameterised with empirical estimates of perceptual range and movements, to simulate dispersal, transfer and settlement stages in fragmented landscapes varying in habitat amount and clumpiness.
